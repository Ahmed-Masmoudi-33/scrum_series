# scrum_series

A collection of simple Python scripts used as part of the scrum_series project.

---

## main.py

### Description
A minimal Python script that prints a greeting message to standard output.

### Run
```bash
python3 main.py
```

### Expected Output
```
Hello World
```

---

## echo.py

### Description
A minimal Python script that prints an echo message to standard output.

### Run
```bash
python3 echo.py
```

### Expected Output
```
hello echo
```
